# 📊 Diagnóstico Estratégico Integral para RappiPlus (Sprint 12)

## 📋 Descripción General del Proyecto
Este repositorio contiene el análisis y diagnóstico estratégico integral desarrollado para **RappiPlus** como proyecto final del bootcamp de Análisis de Datos de TripleTen. El objetivo principal es evaluar el desempeño operativo, comercial y de marketing a partir de datos limpios de catálogo, campañas y órdenes, transformando los hallazgos en recomendaciones accionables para la toma de decisiones estratégicas.

---

## 📁 Estructura del Repositorio

* `S12 Estudiante_Proyecto_Final_revisado.ipynb` — Versión revisada del notebook con ajustes y refinamientos finales.
* `proyecto11_sergio_martinez.pbix` — Archivo de visualización interactiva y tablero de apoyo desarrollado en Power BI.
* `catalog_clean.csv` — Dataset limpio con información del catálogo de productos.
* `marketing_clean.csv` — Dataset limpio con métricas e información de canales/campañas de marketing.
* `orders_clean.csv` — Dataset limpio con el historial y detalle de órdenes.
* `README.md` — Documentación general del proyecto.

---

## 🛠️ Stack Tecnológico y Herramientas
* **Lenguaje y Análisis de Datos:** Python (manipulación de datos, análisis estadístico, métricas de negocio y visualizaciones).
* **Entorno de Trabajo:** JupyterLab.
* **Business Intelligence:** Power BI (`.pbix`) para exploración visual y seguimiento de indicadores.
* **Control de Versiones:** Git y GitHub.

---

## 🎯 Alcance y Metodología
1. **Comprensión y estructuración de datos:** Integración y revisión de las fuentes limpias (`orders_clean.csv`, `catalog_clean.csv` y `marketing_clean.csv`).
2. **Análisis exploratorio y de desempeño:** Evaluación de comportamiento de órdenes, rendimiento por categoría/catálogo y eficiencia de marketing.
3. **Diagnóstico y recomendaciones estratégicas:** Identificación de oportunidades, puntos de fricción y propuestas concretas orientadas a crecimiento, retención y rentabilidad.
